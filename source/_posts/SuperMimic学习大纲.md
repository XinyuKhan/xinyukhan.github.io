## 1. 问题背景与动机

### 1.1 Motion tracking：海量参考轨迹的跟踪问题

- **任务**：给定动捕得到并重定向到 Unitree G1 的参考动作，训练**一个**反馈策略，使机器人在真实动力学下复现动作库中任意一条参考。
- **与经典轨迹跟踪的区别**：
  - 动力学是带接触的混合刚体系统，接触时序不预先给定；
  - 参考来自人体动捕，不保证对机器人动力学可行；
  - 目标是一个对 12.9 万条参考通用的闭环策略（"通用小脑"），而非对单条轨迹求解最优控制。
- **任务定义沿用 BeyondMimic**（观测、奖励、终止、域随机化），SuperMimic 仅做少量修改（见附录 C）。

### 1.2 现有两条扩展路线

| 路线 | 代表 | 做法 | 问题 |
|---|---|---|---|
| 专家 + 蒸馏 | BeyondMimic | 每条/每组动作训练 PPO 专家 → DAgger 蒸馏为学生（扩散模型）→ 分类器引导做下游 | 专家数随动作数增长；蒸馏有损 |
| 单一通用策略 | SONIC | 在整个动作库上直接用 PPO 训练一个策略 | 128 张 L40 × 168 h ≈ 21,000 GPU-h |

### 1.3 PPO 昂贵的根本原因

PPO 的策略梯度是似然比估计：

$$
\nabla_\theta J \approx \mathbb{E}\big[\nabla_\theta \log \pi_\theta(a_t \mid o_t, g_t)\,\hat A_t\big]
$$

- $\pi_\theta$：随机策略；$\hat A_t$：优势估计。
- 式中**不含动力学**：仿真器被当作黑盒，只能通过"试动作、看标量回报"推断梯度方向。
- 每个样本只提供一个标量反馈，要在 29 维动作空间中分辨方向，只能依赖海量样本。
- **关键观察**：所有参考动作由**同一个身体**执行，共享同一套刚体与接触动力学；PPO 没有把这份共享结构以可复用的形式保存下来。

### 1.4 核心思想

学习一个**光滑、可微、覆盖整个动作库**的动力学代理模型，用它提供解析梯度：

- 仿真器只负责产生数据，**梯度从不穿过仿真器**，因此兼容非光滑接触；
- 一个模型摊销所有动作的共享动力学；
- 策略通过模型做 BPTT，获得低方差的一阶梯度。

## 2. 问题形式化

### 2.1 目标条件 POMDP

- 状态 $s_t$、目标 $g_t$、动作 $a_t$；策略为**确定性**：$a_t = \pi_\theta(o_t, g_t)$。
- 在 $s_t$ 下执行 $a_t$ 得到奖励 $r_{t+1}$ 与下一状态 $s_{t+1}$。
- $s_t$ 给出本体观测 $o_t$ 与终止标志 $d_t \in \{0,1\}$。

### 2.2 生存权重与回报

$$
c_0 = 1,\qquad c_{t+1} = c_t\,(1 - d_{t+1}),\qquad
J(\theta) = \mathbb{E}\Big[\sum_{t\ge 0} \gamma^t\, c_t\, r_{t+1}\Big]
$$

- 展开得 $c_t = \prod_{k=1}^{t}(1-d_k)$：在仿真中是"尚未终止"的指示函数。
- $\gamma \in [0,1)$ 为折扣因子。

### 2.3 观测分解与噪声来源

$$
o_t = \bar o_t + \eta_t,\qquad \eta_t \sim \rho_\eta
$$

- $\bar o_t$：无噪声观测；$\eta_t$：已知分布的传感器噪声，在世界模型**外部**采样。
- 采集数据时仿真器执行带噪声动作 $a_t + \epsilon_t$，$\epsilon_t \sim \mathcal N(0, 0.1^2)$，buffer 存储实际执行的动作。

### 2.4 三类信息的区分

| 类别 | 内容 | 使用者 |
|---|---|---|
| 完整状态 $s_t$ | 基座位姿与速度、关节角与关节速度等（马尔可夫） | 世界模型、critic、奖励 |
| 特权信息 | $s_t$ 中真机测不到的部分（基座线速度、全局位置）+ sim context $\xi$ | 世界模型、critic（仅训练时） |
| 本体观测 $o_t$ | 93 维 × 最近 10 帧（见附录 C） | actor（训练与部署） |

- 状态空间模型视角：$s_t$ 为隐状态，$o_t = g(s_t,\xi) + \eta_t$ 为测量方程。
- actor 面对部分可观测问题，10 帧历史起到隐式状态估计的作用。
- 奖励依赖全局刚体位姿，因此是 $s$ 的函数而非 $o$ 的函数。

## 3. 训练循环：Collect → Fit → Imagine

### 3.1 总体结构

每次迭代依次执行三个阶段，单 GPU 共 32 万次迭代：

1. **Collect**：当前策略在仿真器中采集转移，写入 replay buffer $\mathcal B$；
2. **Fit**：用 buffer 中的 $k$ 步窗口拟合世界模型 $f_\omega$；
3. **Imagine**：冻结 $\omega$，在世界模型中想象 $H$ 步，用 BPTT 更新策略 $\pi_\theta$，并拟合 critic $V_\psi$。

```
for each iteration:
    # Collect
    roll out π_θ with action noise in MuJoCo Warp → push to B (FIFO)
    draw reset points by return-based sampling
    # Fit
    sample k-step windows from B; roll f_ω autoregressively on logged actions
    ω ← ω − α_ω ∇_ω L_WM
    # Imagine
    sample start states (s_0, ξ) from B
    imagine H steps through frozen f_ω with π_θ
    θ ← θ + α_θ ∇_θ Ĵ          (BPTT)
    fit V_ψ to λ-return targets of the imagined rollout
```

### 3.2 Collect 阶段

- **并行规模**：每 GPU 4096 个环境；buffer 每环境保留最近 1000 步（约 410 万条转移），FIFO 覆盖。
- **动作噪声的作用**：只为拓宽世界模型被拟合的动作范围（类似系统辨识中的持续激励），而非 PPO 意义上的探索；可选。
- **基于回报的重置采样**：动作时间轴切成 1 s 的 bin，每个 bin 维护运行中的折扣回报估计 $G_b$。重置分布为

$$
p(b) = 0.5\cdot\mathrm{Uniform}(b) \;+\; 0.4\cdot\mathrm{softmax}_b\!\Big(-25\,\frac{G_b}{G_{\max}}\Big) \;+\; 0.1\cdot w^{\text{past}}_b
$$

  - $G_{\max}$：可达到的最大折扣回报；$w^{\text{past}}_b$：该 bin 过去的 softmax 权重（让已学会的难动作保持练习）。
  - 例：$G_b/G_{\max}$ 为 0.2 与 0.9 的两个 bin，logit 差 17.5，被选概率相差约 $e^{17.5}$ 倍。

### 3.3 Fit 阶段与数据复用

- 动力学与采集数据的策略无关，因此**历史策略产生的数据持续有效**（off-policy）；对比 PPO 数据用完即弃。

### 3.4 Imagine 阶段：Dyna 风格的短分支

- 想象轨迹**从 buffer 中的真实状态出发**，且只走 $H=32$ 步（0.64 s）。
- 原因：长时间想象会累积模型误差（compounding error），策略可能利用模型漏洞；短分支把想象锚定在真实数据分布上，视野外交给 critic。
- 类比：短视野内依赖模型精确优化、视野外用终端价值近似，与 receding-horizon MPC 思路相通；区别是这里离线训练闭环策略。

### 3.5 为什么联合训练而非"先训模型再冻结"

- 策略演化导致访问的状态分布漂移（早期多为摔倒，后期出现空翻、侧滚中段状态）。
- 每次迭代更新世界模型，保证它在**当前策略将要访问的区域**保持准确；$\omega$ 只在单次策略更新内部固定。
- 对比 RWM / RWM-U：用其他策略的数据预训练世界模型。

## 4. 可微世界模型

### 4.1 为什么需要代理模型

- 仿真器动力学已知但不提供梯度；接触非光滑，真实导数要么为 0、要么极大。
- 世界模型提供 BPTT 所需的**预测值与雅可比**；优化的是"世界模型眼中的回报"这一代理目标。

### 4.2 确定性模型 + 以 sim context 为条件

| 随机源 | 处理方式 |
|---|---|
| 域随机化参数 $\xi$（摩擦、标定偏差、躯干质心） | 每 episode 采样一次后固定，作为模型输入 |
| 动作噪声 $\epsilon_t$ | buffer 存实际执行动作，作为模型输入 |
| 传感器噪声 $\eta_t$ | 分布已知，模型只预测 $\bar o_t$，外部再加噪声 |

- 结论：给定 $(s_t, a_t, \xi)$，下一状态确定，不需要随机隐变量（对比 Dreamer 的 RSSM）。
- **代价**：无法表示状态突变，因此去掉了 BeyondMimic 的根速度推扰，仅保留物理参数随机化。

### 4.3 模型组成

$$
\hat s_{t+1} = f_\omega(\hat s_t, a_t, \xi),\quad
\hat r_{t+1} = r_\omega(\hat s_t, a_t, g_t),\quad
\hat{\bar o}_t = g_\omega(\hat s_t, \xi),\quad
\hat d_t = d_\omega(\hat s_t, g_t)\in[0,1]
$$

- 带帽子的量为模型对应量；$f_\omega$ 为三层 2048 宽 MLP。
- 每个头可以是学习的或解析的（论文未逐一说明），按逻辑分析：

| 部分 | 可否解析 | 说明 |
|---|---|---|
| 动力学 $f_\omega$ | 否，必须学习 | 非光滑接触正是要用光滑模型替代的部分 |
| 观测头 $g_\omega$ | 可以 | $q-q^0+\Delta q^0$、$\dot q$、$R^\top\omega$、$R^\top[0,0,-1]^\top$ 等均为状态的解析函数；$\xi$ 输入用于标定偏移 |
| 奖励头 $r_\omega$ | 可以 | 正运动学 + 指数核公式 |
| 终止头 $d_\omega$ | 学习（论文明确） | 硬阈值导数处处为 0；学到的概率在阈值附近平滑，提供"快要摔倒"的梯度 |

- 解析头同时给出精确的值与雅可比，避免引入额外梯度误差。

### 4.4 k 步自回归拟合（式 1）

$$
\mathcal L_{WM}(\omega) = \mathbb{E}_{\mathcal B}\sum_{j=1}^{k}\Big[\|\hat s_j - s_j\|^2 + (\hat r_j - r_j)^2 + \|\hat{\bar o}_j - \bar o_j\|^2 + \mathrm{BCE}(\hat d_j, d_j)\Big],\qquad k=8
$$

- 自回归展开：$\hat s_0 = s_0$，$\hat s_j = f_\omega(\hat s_{j-1}, a_{j-1}, \xi)$，动作使用记录值。
- 解析头无对应损失项。
- **单步拟合 vs 自回归拟合** ≈ 系统辨识中的预测误差法 vs 仿真误差法：
  - 单步拟合训练时输入总是真实状态，推理时输入自己的预测 → 分布不一致、误差累积；
  - 自回归拟合把前几步的误差暴露给模型并反向传播，模型学会纠正自身漂移。
  - 例：每步脚高偏低 1 mm，32 步后穿地 3 cm；自回归训练会学到"脚轻微穿地时推回来"。
- 结果：仅用 8 步窗口训练，即可支撑 32 步乃至更长的稳定想象。

### 4.5 一个模型摊销整个动作库

- 数据从 1 h 增至 264 h，8 步预测误差保持在 0.007–0.011（只计状态，按名义误差归一化，在策略 rollout 上在线测量）。
- 解释：新增片段提供的是同一身体的更多物理证据（走路教接触反力，空翻教角动量，侧滚教躯干接触），而非新的学习负担。

### 4.6 开放问题：雅可比未被直接监督

- 损失只监督预测值，BPTT 却依赖 $\partial f/\partial \hat s$、$\partial f/\partial a$。
- 可能的支撑因素（解读）：动作噪声提供局部激励；MLP 的平滑偏置；光滑模型给出"平滑化接触"的梯度，可能比真实接触梯度更有信息量。

## 5. 策略优化：通过世界模型做 BPTT

### 5.1 优化目标（式 2）

$$
\hat J(\theta) = \mathbb{E}_{s_0\sim\rho_0}\Big[\sum_{t=0}^{H-1}\gamma^t\,\hat c_t\,\hat r_{t+1} + \gamma^H\,\hat c_H\,V_\psi(\hat s_H, g_H, \xi)\Big],\qquad H = 32
$$

- $\rho_0$：buffer 中的起点分布；$\hat c_t = \prod_{k=1}^{t}(1-\hat d_k)$；$V_\psi$ 估计视野外回报。
- $\omega$、$\psi$ 在本次更新中固定；梯度**穿过** $f_\omega$（使用其对输入的雅可比），但不更新 $\omega$。

### 5.2 前向递推

$$
\begin{aligned}
&\hat s_0 = s_0\\
&\tilde o_t = g_\omega(\hat s_t,\xi) + \eta_t\\
&a_t = \pi_\theta(\tilde o_t, g_t)\\
&\hat r_{t+1} = r_\omega(\hat s_t, a_t, g_t)\\
&\hat s_{t+1} = f_\omega(\hat s_t, a_t, \xi)
\end{aligned}
$$

- $\theta$ 只在策略调用处**显式**出现；$\hat s_t$ 通过此前各步动作**隐式**依赖 $\theta$。

### 5.3 伴随法推导（简化假设：$\hat c_t$ 视为常数，策略只看当前观测）

**导数约定**：标量对向量的导数为行向量；$\partial y/\partial x$ 为 $\dim y \times \dim x$ 矩阵。

**雅可比记号**（在第 $t$ 步取值）：

| 记号 | 含义 | 维度 |
|---|---|---|
| $r_s^t,\ r_a^t$ | $\partial r_\omega/\partial \hat s,\ \partial r_\omega/\partial a$ | $1\times n_s,\ 1\times n_a$ |
| $F_s^t,\ F_a^t$ | $\partial f_\omega/\partial \hat s,\ \partial f_\omega/\partial a$ | $n_s\times n_s,\ n_s\times n_a$ |
| $\Pi_o^t$ | $\partial \pi_\theta/\partial \tilde o$ | $n_a\times n_o$ |
| $O_s^t$ | $\partial g_\omega/\partial \hat s$ | $n_o\times n_s$ |
| $P_t$ | $\partial \pi_\theta/\partial \theta$（$\tilde o_t$ 固定） | $n_a\times n_\theta$ |
| $A_t = \Pi_o^t O_s^t$ | 动作对状态的敏感度 | $n_a\times n_s$ |

**剩余目标及其递推**：

$$
\begin{aligned}
J_t(\hat s_t;\theta) &= \gamma^t\hat c_t\, r_\omega(\hat s_t, a_t, g_t) + J_{t+1}\big(f_\omega(\hat s_t, a_t, \xi);\theta\big),\\
J_H &= \gamma^H\hat c_H V_\psi(\hat s_H, g_H,\xi),\qquad \hat J = J_0(s_0;\theta)
\end{aligned}
$$

**定义偏导**：协态 $\lambda_t = \partial J_t/\partial \hat s_t$（$\theta$ 固定），$G_t = \partial J_t/\partial\theta$（$\hat s_t$ 固定）。由 $s_0$ 与 $\theta$ 无关，$\nabla_\theta \hat J = G_0$。

**动作敏感度**：

$$
\mu_t \equiv \gamma^t\hat c_t\, r_a^t + \lambda_{t+1}F_a^t
$$

（动作对当前奖励的直接影响 + 通过下一状态对未来的影响）

**协态递推**（对递推式关于 $\hat s_t$ 求偏导）：

$$
\lambda_t = \gamma^t\hat c_t\, r_s^t + \lambda_{t+1}F_s^t + \mu_t A_t,\qquad
\lambda_H = \gamma^H\hat c_H\,\frac{\partial V_\psi}{\partial \hat s}\Big|_{\hat s_H}
$$

**参数梯度递推**（对递推式关于 $\theta$ 求偏导，$\theta$ 经"$a_t\to\hat s_{t+1}$"与"$J_{t+1}$ 的显式参数"两条路径进入）：

$$
G_t = \mu_t P_t + G_{t+1},\qquad G_H = 0
$$

**最终公式**：

$$
\boxed{\nabla_\theta \hat J = \sum_{t=0}^{H-1}\big(\gamma^t\hat c_t\, r_a^t + \lambda_{t+1}F_a^t\big)\,\frac{\partial \pi_\theta(\tilde o_t, g_t)}{\partial\theta}}
$$

- 本质即离散时间最优控制的伴随方程（iLQR 后向传播的一阶部分）。
- 区别：决策变量不是每条轨迹的开环控制序列，而是所有时刻、所有 4096 条轨迹共享的 $\theta$——即"多起点短视野轨迹优化，摊销进一个闭环策略"。
- 对 $N$ 条轨迹求平均：有限和的梯度等于梯度的和；$\eta_t$ 先采样后固定（重参数化）。

### 5.4 去掉简化假设

**生存权重依赖状态**：$\hat c_{t+1} = \hat c_t\big(1-d_\omega(\hat s_{t+1}, g_{t+1})\big)$，把 $\hat c_t$ 增广进状态，新增协态 $\nu_t = \partial J_t/\partial\hat c_t$：

$$
\nu_t = \gamma^t \hat r_{t+1} + \nu_{t+1}(1-\hat d_{t+1}),\qquad \nu_H = \gamma^H V_\psi(\hat s_H)
$$

$\hat s_{t+1}$ 的有效协态变为

$$
\tilde\lambda_{t+1} = \lambda_{t+1} - \nu_{t+1}\,\hat c_t\,\frac{\partial d_\omega}{\partial \hat s}\Big|_{\hat s_{t+1}}
$$

用 $\tilde\lambda_{t+1}$ 替换上文中的 $\lambda_{t+1}$ 即可。含义：状态若朝摔倒概率升高的方向变化，将损失全部未来回报 $\nu_{t+1}$；若终止为硬阈值，该项为 0。

**观测历史与上一步动作**：定义增广状态 $x_t = (\hat s_t, \hat c_t, \tilde o_{t-9{:}t-1}, a_{t-1})$，系统重新成为马尔可夫，推导形式不变；"$a_t$ 影响 $a_{t+1}$"的路径自动包含在增广雅可比中。

### 5.5 视野末端价值项的展开：前向灵敏度 vs 反向协态

$V_H$ 项只通过 $\hat s_H$ 依赖 $\theta$：$\frac{\mathrm d}{\mathrm d\theta}\big(\gamma^H\hat c_H V_H\big) = \gamma^H\hat c_H\,V_s\,S_H$，其中 $S_t = \mathrm d\hat s_t/\mathrm d\theta$。

前向灵敏度递推（闭环雅可比 $M_t = F_s^t + F_a^t A_t$）：

$$
S_{t+1} = M_t S_t + F_a^t P_t,\quad S_0 = 0
\;\Rightarrow\;
S_H = \sum_{t=0}^{H-1}\underbrace{M_{H-1}\cdots M_{t+1}}_{\Phi_{H,t+1}}F_a^t P_t
$$

反向协态（奖励置零时）$\lambda_t = \lambda_{t+1}M_t$，展开后与上式逐项相同。

- 两者仅是矩阵乘法结合顺序不同：前向需维护 $n_s\times n_\theta$ 矩阵（不可行），反向只维护 $1\times n_s$ 行向量——这就是反向传播 / 伴随法的优势。
- 自动微分中 $\lambda_t,\mu_t$ 即反传时流经对应节点的梯度；显存随 $H$ 线性增长（H100 上 $H=128$ 为上限）。

### 5.6 手算验证

$H=2,\ \gamma=1,\ \hat c_t=1,\ V\equiv 0$；$s_{t+1}=s_t+a_t$，$a_t=\theta$，$r=-(s_t+a_t-s^*)^2$。记 $e_0=s_0+\theta-s^*$，$e_1=s_0+2\theta-s^*$。

- 直接求导：$\mathrm d\hat J/\mathrm d\theta = -2e_0-4e_1$。
- 递推：$\lambda_2=0$；$\mu_1=-2e_1$，$\lambda_1=-2e_1$；$\mu_0=-2e_0-2e_1$；$\nabla_\theta\hat J=\mu_0+\mu_1=-2e_0-4e_1$。✓

### 5.7 BPTT vs 似然比：方差对比

一维单步：$s_1=s_0+a$，$r=-(s_1-s^*)^2$，$e=s_0+\theta-s^*$，真梯度 $-2e$。

- BPTT（$a=\theta$）：单样本精确得到 $-2e$，方差为 0。
- 似然比（$a=\theta+\sigma z$）：$\hat g = \frac{z}{\sigma}r$，无偏，方差

$$
\mathrm{Var}(\hat g) = \frac{e^4}{\sigma^2} + 14e^2 + 15\sigma^2
$$

  $e=1,\ \sigma=0.1$ 时约 114；要使均值标准差降到 0.2 需约 2850 个样本。
- 本质：BPTT 每个样本给出完整的 29 维梯度向量；似然比每个样本只有一个标量反馈。

### 5.8 BPTT 的代价与应对

- **雅可比连乘**：$\prod_t \partial f/\partial \hat s$ 在对初值敏感的接触动力学中易爆炸或消失，视野越长越严重。
- **模型偏差**：梯度针对代理模型，视野越长误差越大。
- **应对**：$H=32$；critic 承担视野外回报；梯度先按全局范数 1.0 裁剪、再逐元素裁剪到 0.1。
- **证据**：$H$ 从 64 增至 128，达到目标回报的时间约增至 3 倍，最终回报更低。
- **PPO-WM 对照**：同一世界模型、同样快的 rollout，SuperMimic 达到 PPO-WM 最佳回报所需想象步数少约 64 倍 → 收益来自梯度类型本身。

## 6. Critic、生存权重与 λ-回报

### 6.1 Critic 的角色

- $V_\psi(\hat s_t, g_t, \xi)$：状态价值函数，两层 MLP（256, 128），每个目标接口一个。
  - $\hat s_t$：完整马尔可夫状态，不需要历史；
  - $g_t$：同一状态下，接下来是站立还是空翻，价值不同；
  - $\xi$：摩擦等物理参数影响未来成功率。
- 非对称 actor-critic：critic 使用特权信息，仅训练时存在。
- **与 PPO 的区别**：PPO 中 critic 只提供数值（基线）；在 BPTT 中，$\partial V_\psi/\partial \hat s_H$ 是整条协态链的起点，critic 的**梯度**同样重要。
- **SVG 视角**：$H$ 步模型展开 + 末端 $V$ 相当于构造 $Q_H(s_0,a_0)=\hat r_1+\gamma\hat r_2+\cdots+\gamma^H V_\psi(\hat s_H)$；$H=1$ 时形式接近 DDPG，SuperMimic 可视为 $H=32$ 的随机价值梯度方法。

### 6.2 为什么需要 critic

- 无 critic 时目标只看 0.64 s，策略短视：可能把机器人带到 1 s 后必摔的状态。
- 动作跟踪奖励稠密，故名义跟踪上无 critic 也能达到相近回报；差距体现在扰动恢复。

### 6.3 生存权重的连续化

$$
\hat c_t = \prod_{k=1}^{t}(1-\hat d_k)
$$

- 若 $\hat d_k$ 解释为条件终止概率，$\hat c_t$ 即"活过前 $t$ 步的概率"。
- 例：$\hat d=(0.1,0.3,0.5)\Rightarrow \hat c=(0.9,0.63,0.315)$。
- 索引含义：第 $t$ 步存活即可获得 $r_{t+1}$，终止只影响之后的奖励。

### 6.4 回报、价值与自举

- 回报（从 $t$ 起**未来**的折扣奖励和）：

$$
R_t = \sum_{k\ge 0}\gamma^k r_{t+k+1},\qquad R_t = r_{t+1} + \gamma(1-d_{t+1})R_{t+1}
$$

- 价值：$V(s) = \mathbb{E}[R_t \mid s_t = s]$；由递推取期望得 Bellman 关系 $V(s_t)=\mathbb{E}[r_{t+1}+\gamma V(s_{t+1})]$。
- 想象只有 32 步，完整 $R_t$ 不可得，需要估计。
- **n 步回报**：

$$
R_t^{(n)} = \sum_{j=0}^{n-1}\gamma^j\Big[\prod_{k=1}^{j}(1-\hat d_{t+k})\Big]\hat r_{t+j+1} + \gamma^n\Big[\prod_{k=1}^{n}(1-\hat d_{t+k})\Big]V_{t+n}
$$

  $n$ 小 → 依赖 critic，偏差大方差小；$n$ 大 → 用更多真实（想象）奖励，偏差小方差大。

### 6.5 λ-回报（式 3）及其等价形式

**递推定义**：

$$
\hat R_H = V_H,\qquad \hat R_t = \hat r_{t+1} + \gamma(1-\hat d_{t+1})\Big[(1-\lambda)V_{t+1} + \lambda \hat R_{t+1}\Big],\qquad \lambda = 0.95
$$

直观：到下一步，以 $1-\lambda$ 的权重"停下来相信 critic"，以 $\lambda$ 的权重"继续往后看"。

**等价于 n 步回报的加权平均**（剩余步数 $m=H-t$，可用归纳法证明，$m=2$ 时逐项展开即可验证）：

$$
\hat R_t = \sum_{n=1}^{m-1}(1-\lambda)\lambda^{n-1}R_t^{(n)} + \lambda^{m-1}R_t^{(m)}
$$

- 权重和为 1；$\lambda=0$ 退化为 TD(0)，$\lambda=1$ 为完整剩余想象回报加末端 critic。

**等价于 GAE**：令 $\delta_t = \hat r_{t+1}+\gamma(1-\hat d_{t+1})V_{t+1}-V_t$，$\hat A_t = \hat R_t - V_t$，则

$$
\hat A_t = \delta_t + \gamma\lambda(1-\hat d_{t+1})\hat A_{t+1}
$$

即"GAE 回报 = GAE 优势 + 价值 = λ-回报"。

**数值例**：$r=(1,0.5,0.8)$ 后终止，$\gamma=0.9$，真实 $R_0=2.098$；critic 偏差 $V(s_1)=1.0,\ V(s_2)=0.6$，取 $\lambda=0.5$：$R_0^{(1)}=1.9,\ R_0^{(2)}=1.936,\ R_0^{(3)}=2.098$，加权得 $\hat R_0=1.9585$，与递推结果一致。

### 6.6 Critic 训练

$$
\mathcal L_V(\psi) = \mathbb{E}\sum_{t=0}^{H-1}\big(V_t - \hat R_t\big)^2
$$

- 目标每条 rollout 计算一次，拟合时固定（stop-gradient）。
- 只在想象转移上训练；每次更新 5 个 epoch × 4 个小批量。

### 6.7 与 SHAC 的异同

| | SHAC | SuperMimic |
|---|---|---|
| 梯度来源 | 可微仿真器 | 学到的世界模型 |
| 终止处理 | 硬终止 | 软生存权重 $\hat c_t$ |
| 目标网络 | EMA 目标 critic | 无 |
| 共同点 | 短视野 BPTT 更新 actor，critic 承担视野外价值，λ-回报 | 同左 |

- 此前用解析梯度做动作跟踪的工作（SuperTrack、ControlVAE）常省略 critic。

### 6.8 实验：视野与推扰恢复

- **视野扫描**（LAFAN1，目标回报 0.82）：无 critic 时 $H\le16$ 失败；有 critic 时 $H=16$ 追平无 critic 的 $H=32$；$H=32$ 最快；$H=8$ 两者都失败。
- **推扰恢复**（静态 T 字姿势，0.5–4 m/s 速度冲击）：有 critic 在 0.5–2.4 s 内恢复；无 critic 从不稳定，0.5 m/s 即踉跄，4 m/s 摔倒。
- **解释**：恢复需要 1–2 s（50–100 步），远超窗口；窗口内迈步会降低跟踪奖励，短视策略选择维持姿势。
- **启示**：名义回报相近的策略鲁棒性可以完全不同，评估 tracker 需单独测抗扰能力。

## 7. 实验分析

### 7.1 评价指标

- **归一化回报**：整个 episode 无折扣奖励和 ÷ 可能的最大值；提前终止直接拉低分数。
- **失败动作数**：每个动作从第一帧播放一次；摩擦 1.0、无域随机化、无观测噪声、确定性物理；触发 SuperMimic 训练终止条件即失败。
- **注意**：基准动作对两种方法都是训练动作，衡量的是**覆盖率**而非泛化。

### 7.2 主对比：SuperMimic vs SONIC

| | SONIC（发布 checkpoint） | SuperMimic |
|---|---|---|
| 训练方法 | 仿真中无模型 PPO | 通过世界模型 BPTT |
| 硬件 | 128 × L40 | 1 × H100 |
| 时间 | 168 h | 3 h 超过 SONIC 回报 |
| GPU-hours | ~21,000 | 3 |
| 数据 | 611 h | 264.56 h（BONES-SEED 公开子集） |
| 归一化回报 | 0.90 | > 0.90 |
| 失败动作（/129,514） | 179 | 25；2 GPU × 9.8 h 后为 0 |

- 比例：墙钟约 56 倍（> 50×），GPU-hours 约 7200 倍（> 1000×）；3 h 包含完整训练循环，不含评估。
- "3 h"为保守取点：此后每个 checkpoint 领先 SONIC 的幅度至少为最佳结果差距的一半。
- **公平性**：数据少 2.3 倍；H100 相对 L40 的 fp32 峰值 0.74×、tensor core 峰值 5.5×；两者相乘约 13×，不足以解释 1000×。
- **补充考量**：评测采用 SuperMimic 的终止判据；SONIC 的算力还包含多种目标编码器的联合训练；SONIC 在更大数据上训练、在子集上评测；SONIC 自报算力在不同版本中不一致（9k–21k GPU-h），取最小值结论仍成立。

### 7.3 受控对比：PPO-Sim（LAFAN1，40 片段，2.45 h）

- 共享动作、观测、奖励、终止、域随机化、网络大小与评测协议；PPO 超参来自 BeyondMimic；每 GPU 8192 个环境（SuperMimic 的两倍）。
- SuperMimic 单 GPU 1.2 h 达到 0.82；PPO-Sim 18 h 内未达到，最终回报 1/4/8 GPU 分别为 0.60/0.70/0.72。
- 意义：排除数据与硬件混杂，是最硬的证据；PPO 加 GPU 收益迅速饱和。

### 7.4 三个机制性实验

| 性质 | 证据 | 说明 |
|---|---|---|
| 一个模型摊销动作库 | 1→264 h，预测误差 0.007–0.011；达到目标回报的 GPU-h 增长远低于线性 | 数据集子集 1、7、40、264 h |
| 想象比仿真快 | 2k–16k 环境时快 > 10×，64k 时 62× | 仿真每控制步 4 个 5 ms 子步；模型一次 MLP 前向，TF32 |
| 一阶梯度更省样本 | 达到 PPO-WM 最佳回报的想象步数少约 64× | PPO-WM 取四种批量中最好的 |

- 粗略直觉（非论文分解）：约 10× 速度 × 约 64× 样本效率 × off-policy 复用 ≈ 观察到的三个数量级。

### 7.5 失败动作分析

| 动作组（数量） | SONIC | SuperMimic 1 GPU × 3 h | SuperMimic 2 GPU × 9.8 h |
|---|---|---|---|
| 侧滚（22） | 全部 22 | 2 | 0 |
| 空翻 360°/180°/90°（44） | 全部 44 | 1 | 0 |
| fire-in-the-hole 转身（20） | 3 | 3 | 0 |
| 交叉腿（10） | 9 | 0 | 0 |
| 躺下、休息、起身（99） | 28 | 8 | 0 |
| 立定跳远（24） | 15 | 0 | 0 |
| 舞蹈套路（8） | 全部 8 | 0 | 0 |
| 其余动作（129,287） | 50 | 11 | 0 |
| **合计（129,514）** | **179** | **25** | **0** |

- SONIC 失败集中于高动态、少样本动作且整组失败；v1.1 checkpoint 失败 239 个。
- SuperMimic 在任何一组上的失败数都不多于 SONIC。
- 可能原因（推测，论文未消融）：稀有难动作在 PPO 中梯度信号被淹没，而 SuperMimic 的重置采样把 40% 预算投向表现最差的 bin；高动态动作对时序敏感，精确梯度更易找到可行解。

### 7.6 证据强度评估

- **强**：PPO-Sim 受控对比；PPO-WM 对照；与 SONIC 的数量级差距。
- **需谨慎**：图中未报告种子方差（作者称多种子稳定）；失败基准为理想化条件、仅训练动作；真机为定性展示（跳跃、侧滚、90° 与 360° 空翻）；下游实验单种子。

## 8. 下游目标接口

### 8.1 策略结构：编码器 + 隐变量 + 共享解码器

$$
z = \mathrm{enc}_{\theta,i}(g)\in\mathcal Z\subset[-1,1]^{32},\qquad a = \mathrm{dec}_\theta(z, o)
$$

- **从训练开始即为此结构**，整体端到端训练；不存在先训完整策略再拆分或蒸馏的过程。
- 隐变量为 32 维连续向量，tanh 限幅；**不是 VAE**（无均值方差采样、无 KL 项），**无量化**。
- 解码器相当于"技能库"，$z$ 为"执行何种技能"的代码；32 维瓶颈的目的是允许其他编码器接入同一隐空间。

| 网络 | 输入 | 结构 |
|---|---|---|
| 动作编码器 | 未来 $K=10$ 帧参考 | MLP (2048, 1024, 512, 256) |
| 速度编码器 | 归一化指令 $(v_x,v_y,\omega_z)$ + 最近 10 帧观测特征 | MLP (256, 256) |
| 共享解码器 | $z$ + 最近 10 帧观测 | MLP (2048, 1024, 512, 256) |

### 8.2 多接口目标

- 每个接口 $i$ 对应一个 POMDP $\mathcal M_i$：目标空间 $\mathcal G_i$、奖励 $r_i$、终止 $d_i$、critic $V_{\psi_i}$。

$$
\max_\theta\ \mathbb{E}_{i\sim p(\mathcal I)}\big[\hat J_i(\theta)\big],\qquad \pi_i(o,g) = \mathrm{dec}_\theta(\mathrm{enc}_{\theta,i}(g), o)
$$

- 所有接口共用同一个动力学模型 $f_\omega$（身体物理与指令形式无关），只替换奖励与终止。

### 8.3 速度指令的定义

- $g_t=(v_x, v_y, \omega_z)$：朝向（仅偏航）坐标系下的目标平面根节点速度 + 世界系偏航角速度。
- 从参考计算：参考**根节点（骨盆）**速度在参考自身朝向系下的 25 帧居中平均（0.5 s，约一个步态周期，滤除步态内的速度起伏）。

### 8.4 两种训练方式

| | 蒸馏版本 | RL 版本 |
|---|---|---|
| 指令来源 | 全部从参考计算 | 50% 来自参考；50% 均匀采样并保持 5 s：$v_x\in[-1.5,2]$，$v_y\in[-1.32,1.32]$，$\omega_z\in[-3.35,3.35]$，10% 置零 |
| 奖励 | 动作跟踪奖励（复现对应参考） | 速度跟踪奖励（附录 C） |
| 终止 | 跟踪终止 | 仅摔倒 |
| 对齐损失 | — | 参考指令 rollout 上，权重 0.1，将速度隐变量拉向动作隐变量（对后者 stop-gradient） |

- 两者都在 Imagine 阶段通过世界模型 BPTT 训练，区别仅在奖励与指令来源；"蒸馏"指学习信号来自动作库，而非传统师生模仿。
- 蒸馏的固有局限：只覆盖库中出现过的速度组合；同一速度对应多种动作（风格、步幅）时目标不可预测。

**速度跟踪奖励主项**：

$$
r_{\text{lin}} = \exp\!\big(-\|v_{xy}-v^{cmd}_{xy}\|^2/0.5^2\big),\qquad
r_{\text{yaw}} = \exp\!\big(-(\omega_z-\omega^{cmd}_z)^2/0.5\big)
$$

### 8.5 梯度路由

- 下游接口的回报梯度穿过解码器到达该接口编码器，但对**解码器参数** stop-gradient；解码器只由动作跟踪目标训练。
- 即 $\sum_t \mu_t P_t$ 中只保留对 $\theta_{\text{enc}}$ 的部分；解码器的雅可比 $\partial\,\mathrm{dec}/\partial z$ 照常参与链式求导。
- 目的：保护技能库不被下游奖励改写。

### 8.6 实验设置要点

- 论文共有三次相互独立的训练：
  1. 主实验：全量 129,514 个动作，仅动作跟踪接口；
  2. 速度接口蒸馏版本；
  3. 速度接口 RL 版本。
- 训练 2、3 各自**从零开始**，动作编码器、解码器、速度编码器同时训练 10 万次迭代；**数据仅为 LAFAN1 与 BONES-SEED 中筛选出的走跑子集**；环境与想象批量各一半用于两个接口。
- 动作跟踪那一半是必需的：解码器只靠它获得梯度，对齐损失也需要动作编码器的输出。
- 只用走跑子集的原因：速度指令无法区分原地空翻、跳舞与站立等动作（平均速度都接近 0）。

### 8.7 结果：阶跃响应测试

- 协议：从站立开始，固定指令 5 s，每个指令 4 次；相对稳态误差 = 最后 2 s 平均速度误差范数 / 指令范数，取未摔倒试次的中位数；三个平面各 15×15 网格，去掉站立指令，共 672 个。
- RL 编码器在 650 个上更好，蒸馏在 15 个上更好；相对误差中位数 0.16 vs 0.49。
- 蒸馏在 7 个"平移 + 转向 ≥ 2.8 rad/s"的指令上每次都摔倒——动作库几乎没有对应数据。
- RL 能覆盖库外指令的原因：直接优化任务目标，且共享动力学使世界模型在这些状态下仍可用。

### 8.8 讨论：接口的训练方式

- **论文自述局限**：速度奖励不更新解码器，因此联合训练在效果上等同于先训跟踪器、再训速度编码器；让速度奖励更新解码器是否有益未测试。
- **作为"小脑基座"的后训练方案**：用全量数据训练基座 → 冻结动作编码器与解码器 → 新建速度编码器与速度 critic，世界模型从基座检查点继续训练 → 仅速度接口采集数据、计算对齐与速度奖励。要点：世界模型需继续更新（库外指令会访问新状态）；若后训练要更新解码器，需混入跟踪数据以防遗忘，实质又回到联合训练。
- **纯隐空间对齐（离线回归）的局限**：一个速度对应多个 $z$ 导致学到平均；开环监督与闭环执行的协变量偏移；隐空间误差不等于任务误差；无法覆盖库外指令；无法保证**实际达到的**速度（重定向不完美、跟踪误差）。可作为低成本初始化；用跟踪器在仿真中实际达到的速度重标注指令（事后重标注）可消除速度偏差。

## 10. 局限与延伸方向

### 10.1 论文自述局限

1. 多接口训练研究不足（见 8.8）。
2. 世界模型只从仿真数据学习；真机数据可用于改进模型，可微性可支持系统辨识。
3. 无地形与物体交互，仅平地训练；数据过滤也因此剔除楼梯、椅子、箱子等动作。

### 10.2 延伸：用真机数据改进世界模型与策略

- **核心逻辑**：真机只提供数据修正动力学模型；奖励是状态与参考的固定解析函数，在仿真与真机中相同；只要模型对真机动力学预测准确，在模型中提升回报即对应真机提升（模型误差 × 视野长度界定回报差，即 simulation lemma）。
- **数据混合问题**：确定性模型对同一 $(s,a,\xi)$ 无法同时拟合仿真与真机的不同 $s'$；仿真数据量远大于真机，不加区分会把修正冲掉。
- **区分数据来源的方法**：

| 方法 | 做法 | 适用 |
|---|---|---|
| 来源条件 | $\hat s_{t+1}=f_\omega(\hat s_t,a_t,\xi,e)$，$e\in\{e_{sim},e_{real}\}$（one-hot 或可学习嵌入）；批次中强制真机数据占固定比例 | 通用 |
| 残差模型 | $f_{real}=f_\omega+\Delta_\phi(s,a)$，$\Delta_\phi$ 只在真机数据上训练 | 灰箱建模思路 |
| 参数辨识 | 固定模型，对 $\xi$ 求梯度拟合 $\xi_{real}$ | 差异可由已建模参数解释时 |

- **真机数据的 $\xi$**：填随机化范围中心值，或将 $\xi_{real}$ 设为可学习参数一并拟合。
- **内外双层循环**：
  - 外层（以真机部署为单位）：部署 → 采集 → Fit（真机 $e_{real}$ + 仿真 $e_{sim}$）；
  - 内层（在模型中）：**冻结世界模型**，以 $e_{real}$、$\xi_{real}$ 为条件，从真机 buffer 取起点想象，BPTT 更新策略（热启动、小学习率），critic 同样以 $e$ 为条件重新拟合；
  - 冻结过久的风险：策略漂离数据覆盖区并利用模型错误 → 限制更新幅度、短视野、真机起点、不确定性惩罚（如 RWM-U），最根本的是回到外层采新数据。
- **仿真的角色**：初始阶段必需（产生可上真机的初始策略与模型）；微调阶段作为先验与兜底（覆盖真机不敢去的状态、防止遗忘）。策略始终在世界模型中训练。
- **例：电机延迟**：修正后模型学到 $\hat s_{t+1}$ 更多依赖 $a_{t-1}$，协态把落地误差归因到更早动作，策略学会提前伸膝。
- **真机难点**：完整状态不可直接测量（基座线速度、全局位置需状态估计或动捕，估计误差直接进入模型训练与评估）；数据分布窄、采集有风险、无自动重置。
- **验证**：在留出的真机轨迹上比较 $e_{real}$ 与 $e_{sim}$ 的 8 步预测误差，确认条件生效。

### 10.3 其他开放问题

- 确定性世界模型无法表示外力、碰撞等状态突变，抗扰能力只能间接获得。
- 雅可比与 critic 梯度未被直接监督，其有效性缺乏理论分析。
- 评估层面：泛化到未见动作、真机定量指标、种子方差。
- 下游接口未在全量基座上验证。

### 10.4 论文最想推动的方向

- 单卡数小时即可完成一次全量训练 → 动作跟踪的扩展定律（数据量、多样性、模型规模、训练时长）可以被系统地测量。

### 11.1 方法定位（论文 Table 1）

### 11.2 隐空间结构对比

| | SuperMimic | SONIC | VAE 类（ControlVAE、PhysicsVAE） |
|---|---|---|---|
| 隐变量 | 32 维连续，tanh 限幅 | FSQ 量化的离散 token | 连续，带高斯后验 |
| KL 先验 | 无 | 无 | 有 |
| 辅助重建 | 无 | 机器人动作解码器 | 有 |
| 编码器 | 动作参考、速度 | 机器人动作、人体动作、混合 | — |
| 网络 | MLP | MLP（规划器另为 Transformer/Conv1D） | — |

- **VAE**：编码器输出 $\mathcal N(\mu,\sigma^2)$，重参数化采样 $z=\mu+\sigma\odot\epsilon$，损失含 $\beta\,\mathrm{KL}(q(z|x)\,\|\,\mathcal N(0,I))$；隐空间可采样、可插值，便于下游探索；代价是信息压缩与后验坍塌风险。
- **量化的典型用途**：
  1. 上游为需表示多峰分布的生成模型（离散 token + 交叉熵；连续空间也可用扩散 / 流匹配替代）；
  2. 硬性保证解码器输入落在训练见过的有限集合内，对多来源输入自带去噪与对齐；
  3. 带宽、存储、可枚举词表等工程需求。
- **相关概念辨析**：VQ 可避免 VAE 的后验坍塌；码本坍塌是 VQ 自身的问题，FSQ 用于避免它（SONIC 选 FSQ 的理由）；GAN 的模式坍塌一般不靠量化；回归多峰目标的"模式平均"需上游输出 token 分布并采样才能缓解。
- **SONIC 量化而 SuperMimic 不量化的合理解释**（两篇论文均未做消融，属推断）：SONIC 定位为多入口的"通用 token 空间"，需对齐人体、机器人、混合等异构输入；SuperMimic 主线只有重定向后的机器人参考这一个入口，量化收益有限且引入量化误差，连续空间也与"精确解析梯度"的定位更一致。
- **速度控制路线对比**：SONIC 用运动学规划器把速度 / 风格指令生成为全身参考，再交给跟踪器；SuperMimic 用速度编码器直接把指令映射到隐空间。
